# kairon
LLM が「現在の状況」を読んで実行可否を判断する、文脈ベースのスケジューラ概念です。

## コンセプト
- `cron` は `chronos`（時計的・定量的な時間）に由来し、時刻・曜日・日付が一致するかでジョブを動かします
- `kairon` は `kairos`（機を見る、文脈上ふさわしい時）に由来する造語で、LLM が「今がその機会か」を判断します
- 発火条件は自然言語で書けます（例: 「ログが 3 行以内のとき」「平日の朝に 1 回くらい」）

| 概念   | 判断対象                       |
| ------ | ------------------------------ |
| cron   | 時刻・曜日・日付が一致するか   |
| kairon | 文脈上、今がその機会か         |

`kairon` はプロダクト名ではなく **概念名／パラダイム名** として位置づけています。
